## Fixed-point operator and unique loss

Use dimensionless canonical Phat,Ahat,qhat,lhat,uhat and state s=(xhat,yhat,what). R=.1*I,sigma1e-6,alpha1. `x+=solve(Phat+sigma*I+Ahat'*R*Ahat, sigma*x-qhat+Ahat'*(R*w-y))`; `w+=clip(Ahat*x++y/R,lhat,uhat)`; `y+=y+R*(Ahat*x+-w+)`. Matrix factorization is a function of the actual input; no detached solve or family-inferred coefficient is used. Clamp derivative is1strictly inside its bounds and0outside or exactly at either bound. This registered subgradient choice overrides any framework boundary default and requires explicit tests. Interval endpoints stay data constants, not trained parameters.

Unroll s1=T(s0) through s5=T(s4), then compute one additional transition T(s5) ONLY to evaluate the residual. Loss per frame is `L_fp=(||T_x(s5)-x5||²/n + ||T_y(s5)-y5||²/m + ||T_w(s5)-w5||²/m)/3`. This is the squared final residual AFTER five transitions, not the fifth transition residual, not a trajectory sum and not distance to a reference solution. Gradients propagate through all six operator calls and the network. m>=1for every registered head. K0diagnostics evaluate T(s0)-s0 with the same equation and are not additional methods. All state blocks are already nondimensionalized; block division by n/m is the only loss normalization. Value/gradient probes must include active kinks, out-of-box starts, nonzero dual starts and scalar-rho/equality parity with the actual installed C solver before training.

## Source weighting for fit, training, validation and calibration

For a given method let F be its eligible family set, R_f its frozen eligible regimes and U_fr its32train or8validation/calibration source units. Each source unit receives weight `1/(|F|*|R_f|*|U_fr|)`; each of its Tframes receives that weight/T. N12 has T32, others T1. For a shape head, condition these weights on its eligible family/regime cells and renormalize to sum1. Fit/train/stop each MLP head with these conditional weights; a head present in one rare shape cannot be ignored by a larger head. One registered L2WS bundle contains every head, each trained under the same schedule and seed. GNN uses the full method-level weights above. Batch gradients accumulate the exact weighted full-epoch objective: partition sorted source units into fixed batches, scale their weights by the total prescribed epoch weights, and do not reweight by the final batch length. Shuffling uses its own epoch RNG receipt, never changes weights. Validation/early-stop uses the same full weighted objective without updates. No frame is duplicated to simulate source weight.

## GNN graph statistics, labels and loss

For each graph separately and each feature coordinate, compute population mean over all its variable+constraint nodes and population variance with ddof0; normalize by its standard deviation if positive, else1.
