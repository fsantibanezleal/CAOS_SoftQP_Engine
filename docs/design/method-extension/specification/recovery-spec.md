## S: unchanged symmetric separable lift

Take the exact `lift_problem` symmetric branch when lower/upper coefficient arrays are elementwise identical. `reference.lift` variables are `(original x, xi, w, s)`. New separable problems have no Huber w variables; retain that empty block. xi is one signed variable per soft row with linear coefficient0 and positive quadratic coefficient; all remaining soft rows receive one nonnegative s each. Relaxed-row s allocation follows original-row order, including an entirely free soft row. That free row retains an irrelevant penalized slack and a free top row; its optimum slack is0. No new code removes it. For the primary population every soft linear coefficient is positive, so all soft slacks are s.

Rows are: all m original top rows in original order, then a second lower-side row for every relaxed row with both finite endpoints, then s>=0 in s-allocation order. A relaxed top row is its upper side with coefficient -s when upper is finite (or both endpoints are infinite); otherwise it is the lower side with +s. A pure-quadratic xi stays in its original interval row with coefficient+xi. The original signed dual equals its top-row signed dual plus its extra lower-row signed dual when present. Nonnegative-s bound multipliers do not enter the original row dual. Recover original x from the leading original-n coordinates. Entirely free rows have independently certified dual0 even if their redundant lifted constraint representation remains present.

## A: unchanged asymmetric separable lift

Use `lifting._asymmetric` exactly: scan original rows; a hard row emits its unchanged interval row. A soft row emits lower then upper side, only when finite, allocating one new nonnegative slack per emitted side. Lower constraint is a*x+s>=l; upper is a*x-s<=u. Variables are original x then these side slacks. After all side/hard rows, append each slack>=0 in allocation order. Costs are that side's linear and half-quadratic coefficients. Entirely free soft rows emit neither a side nor a slack. Original signed row dual is the sum of signed emitted interval duals for that original row; a missing free row receives0. The saved original-row map is validated against this ordering, not trusted because its outer hash matches.

## G: unchanged disjoint peak epigraph

Use the existing `_assemble(problem,'epigraph')` ordering. Hard rows first, preserving their intervals even if free; then finite upper grouped sides in original index order; then finite lower grouped sides; then t>=0 for live groups in ascending group ID. A group is live when its nonzero-cost rows have at least one finite side. No variable is allocated for an entirely free or zero-cost group; its contribution/dual is0. Variables are original x followed by t_live. Upper row is `c_U*A*x-t<=c_U*u`; lower row is `-c_L*A*x-t<=-c_L*l`. Its objective tail is a*t+b*t²/2.

For one-sided upper-form inequalities let lambda_U/lambda_L>=0 be the backend nonnegative multipliers; omitted sides have multiplier0. Recover `y_i=c_Ui*lambda_Ui-c_Li*lambda_Li` on grouped rows. Hard rows recover their ordinary signed interval dual. If t>=0 has signed interval multiplier y_t<=0, define mu=-y_t>=0. Every group must satisfy `a+b*t-sum(lambda_U+lambda_L)-mu=0`, `mu*t=0` and side complementarity. Include these diagnostics in the saved result and validate them independently; original-space Fenchel metrics in numerical-spec.md are additionally mandatory. The original y is not an unweighted lambda sum.

## D: singleton representation for directional native projection

Every symmetric separable soft row is an individual group, scales1,group-linear equal to its common linear coefficient and group-quadratic equal to its common quadratic coefficient. Intervals are ordered, so positive lower and upper violations cannot coexist; max(lower_violation,upper_violation) therefore has the exact same linear/quadratic cost as their sum. Hard rows remain ungrouped. This declared conversion is included in the matrix, including one-sided pure-L1 cases. Mixed asymmetric side coefficients use no singleton conversion unless both are equal; the general scalar-scale relation is not guessed. Groups N05/N13 retain their genuine multirow definition. This is the same directional method on another exact input representation, not another counted method.

## Backend normalization and empty/free rows

The canonical lifted object with ordering S/A/G is saved before backend conversion. Clarabel emits exact equalities into ZeroCone and splits each remaining finite interval into upper then lower nonnegative-cone rows, scanning canonical rows in order. Fully free rows create no backend cone row but remain in the saved recovery map with dual0. PIQP and ProxQP emit exact equalities, in canonical-row order, to their equality block and retain all other rows with at least one finite bound in the interval block. Empty equality/inequality blocks have shape(0,n), not an inferred missing dimension. Recover canonical interval dual as upper-lower for Clarabel/PIQP or native signed interval z for ProxQP, then apply S/A/G. Matrix shape includes slacks even when backend free rows are omitted.

DAQP/GNN one-sided graph encoding splits finite intervals upper then lower; each hard equality becomes one immutable equality row instead of two opposite inequalities. Graph row mapping stores canonical-row ID, side, sign and equality flag. All matrices, transformed RHS values, objective coefficients, row maps and dimensions must agree with a separately constructed small analytic oracle before production. A PSD covariance's nonunique primal coordinates are never forced to match one arbitrary reference solution.

The shape inventory in semantic-matrix.json is based on these exact lifts before backend free-row removal. It is not selected after an example succeeds. An undeclared learned shape is an explicit unsupported-input refusal, not an invented checkpoint, missing-package waiver or a mathematical-incompatibility claim about a supported primary cell.
